# 决策规则速查 — 科技英文论文修改：三书方法整合

| 能力 | 一句话规则 |
|---|---|
| 体裁与篇章功能 | 先按体裁识别段落功能，再修改语言；沿用有效结构，用已有证据写清贡献。 |
| 方法与结果的准确表达 | 精确保留谁做了什么、在何条件下获得何结果，按章节类型安排解释。 |
| 标题、摘要与结论对齐 | 从正文已经支持的信息提炼标题与摘要，结论突出认识及意义，避免重复摘要。 |
| 语序、语法与修饰关系 | 先明确施事、受事及修饰范围，再用语法和语序准确表达原意。 |
| 段落组织与信息衔接 | 用主题、关键词与明确关系推进信息；连接词只在实际关系需要时使用。 |
| 精简与专业表达 | 删低信息表达，保留专业概念和必要条件；按具体结构选择名词化或动词化。 |
| 因果、确定程度与适用范围 | 观测直接表达，解释按证据限定；用具体范围代替多层保留或无据强化。 |
| 文献综合与全文终审 | 按科学问题比较文献，保留归属与条件；最后逐项核对改稿是否忠实于原文。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
