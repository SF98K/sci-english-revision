# 可执行规则与来源台账

C/W/G 对应三书；行号针对完整重建的 Library 渲染文本。原书规则、情景适用条件和用户的保真要求结合执行。案例只是支持素材；不能把虚构科学内容写入真实论文。

## f01 — 按体裁、受众和目的确定修改标准

任务：T01, T14。来源：C 第1章；L329–395

summary: 同一内容对专家、跨学科读者、学生或一般公众有不同解释深度。 编辑前区分文章类型与目的，再同时检查组织、语言惯例、语法及科学内容。 不把面向学生的实验报告方式自动迁移为期刊论文方式。

inputs: ["已有文本", "文章类型", "可得的读者或期刊信息"]

steps: ["辨认体裁和阅读对象", "明确本段要完成的功能", "按五类维度诊断", "在相应维度作必要修改"]

outputs: ["简要修改约束", "符合受众与功能的改稿"]

missing_conditions: 目标期刊未知时采用通用科学读者标准，具体格式暂不判断；不得据此虚构投稿要求。

## f02 — 读—析—写的目标文本学习流程

任务：T01, T02, T05, T11。来源：C 第1章 L293–329；G 前言 L67–89

summary: 先选相关体裁的文章，再分析其结构与表达承担的任务，最后应用到自己的内容。 学习的是交际功能及惯例，而不是复制他人的结果或整段措辞。 三书例文能提供起点，实际目标文本用于校准特定领域。

inputs: ["待改文本", "可得的同类型目标文章"]

steps: ["选择相近领域和体裁的文本", "标注功能与组织", "辨认可迁移表达", "用自己的研究信息重写", "检查未复制独特措辞与科学内容"]

outputs: ["基于范例功能的改稿", "少量表达选择依据"]

missing_conditions: 无目标文章时可使用书中通用组织原则，但不宣称已匹配某个期刊；作者国籍不是质量标准。

## f03 — 用研究核心校准引言与讨论的范围

任务：T01, T02, T05, T14。来源：C 第2章 L1253–1265；G Unit1 L184–210

summary: 引言逐步聚焦到本研究，方法与结果给出具体工作，讨论再说明较广意义。 修改时先确定研究实际完成了什么，再校准两端的信息范围。 这是研究论文的组织图景，不是强制每段先宽后窄的句式规则。

inputs: ["完整研究论文或足以辨认结果的章节"]

steps: ["确认方法和关键结果", "检查引言是否导向该问题", "检查讨论是否解释对应结果", "删除失去连接的外围叙述"]

outputs: ["范围一致的篇章", "需要调整的位置清单"]

missing_conditions: 只有局部文本时只能作局部检查；综述须按归纳比较目的调整，不能据此增添实验章节。

## f04 — 引言的领域—问题—本研究组织

任务：T02, T13。来源：C 第6章 L5479–5515；G Unit1 模型 L606–618

summary: 用必要背景建立研究领域及其意义，说明已有工作与当前问题，再引入本研究。 文献背景选择对当前研究有实质作用的内容，不做无差别穷举。 研究缺口需要已有文献支持，不能为了凑语步临时捏造。

inputs: ["引言草稿", "已有文献与研究目标"]

steps: ["标记领域与背景", "确认问题及其依据", "检查本研究如何回应问题", "重排重复和脱节内容", "保留仅在适用时出现的结果预告"]

outputs: ["功能完整的引言", "无依据的缺口声明提示"]

missing_conditions: 书中语步为组织起点；具体文章可组合语步，不强制段数、开头句或缺口措辞。

## f05 — 按材料、实验和数值方法组织可复现描述

任务：T03, T11。来源：C 第3章 L1720–1760；G Unit2 L1396–1406、L1538–1548；W §10.6 L3936–3950

summary: 先交代材料或研究对象，再按程序与仪器组织实验方法，最后说明适用的数值分析。 概要、具体参数、选择理由和质量保障需各自承担清楚功能。 合成论文可把具体试剂放到相应合成条目，不机械拆开信息。

inputs: ["方法草稿", "原有参数和实验记录", "仪器及分析信息"]

steps: ["区分一般信息和具体步骤", "按实际依赖组织程序与仪器", "核对量温度时间条件和分析方法", "精简教学式细节", "列出影响复现的缺项"]

outputs: ["清楚且保留条件的方法文本", "缺失信息清单"]

missing_conditions: 不补造参数、仪器或理由；能否省略普通操作由复现需要决定，不能仅因专家受众就删掉关键条件。

## f06 — 按证据逻辑组织结果组

任务：T04, T14。来源：C 第4章 L3112–3148；G Unit3 L2430–2448；W §10.7 L3954–3959

summary: 每组结果先给必要的方法提醒或图表入口，再突出关键发现、趋势和意外结果。 组与组按支持研究结论的逻辑连接，而非照抄实验日志的时间顺序。 C针对独立结果章节强调描述；G的菜单允许解释、模型比较及意义，需先辨认章节约定。

inputs: ["结果文本", "图表及控制实验信息", "独立或合并章节类型"]

steps: ["列出主要证据组", "根据研究问题排序", "为每组建立图表入口与关键发现", "保留与假设不符的结果", "按章节类型安排解释"]

outputs: ["有证据推进关系的结果章节", "可核对的图文对应"]

missing_conditions: 缺图表时不推断其趋势；不能把“结果不得解释”当作所有学科和合并章节的禁令。

## f07 — 结果—解释—已有证据—意义的讨论流程

任务：T05, T06, T12, T13。来源：C 第5章 L4464–4506；G Unit4 L3642–3664；W §10.8 L3961–3972

summary: 选择要解释的关键结果，给出支持其含义的推理与文献，再说明贡献或应用。 独立讨论章节可短暂提醒结果；合并结果与讨论通常不需要重新复述。 多组讨论与结果顺序对应，避免解释证据失联。

inputs: ["结果与讨论草稿", "已有引用", "作者所支持的解释"]

steps: ["识别每段结果锚点", "区分观察与解释", "将文献连接到相应推理", "检查其他解释与范围", "以数据支持的贡献收束"]

outputs: ["证据相称的讨论", "必要的待作者判断问题"]

missing_conditions: 不为强化叙事添加机制；并非每项工作都有实际应用，不能强造应用段落。

## f08 — 先理解与独立笔记，再改述和归类文献

任务：T13。来源：C 第6章 L5425–5437

summary: 先理解原文，离开原句记录相关要点，再用自己的结构概括。 回到原文核对意义和归属，保存文献信息并用主题词归类。 这是一套形成综合材料的流程，不能简化为逐词替换同义词。

inputs: ["需引用的原文", "本文论点", "已有参考文献信息"]

steps: ["读懂与当前论点相关的内容", "独立记下关键含义", "按本文目的重新组织", "回原文核对条件和结论力度", "保留来源并按主题归类"]

outputs: ["可追溯的改述或主题笔记", "适合整合的引用片段"]

missing_conditions: 未取得文献原文时不声称已核查其结论；不虚构书目细节。

## f09 — 按研究目的、方法和主要发现压缩摘要

任务：T07, T14。来源：C 第7章 L6615–6643；G Unit5 L4102–4126

summary: 摘要交代研究完成什么、如何完成以及得到什么主要发现。 方法细节随研究目的调整，主要发现通常是核心篇幅。 G区分较结构化和高度压缩两种形式，后者可把功能合并在一句中。

inputs: ["论文核心内容", "摘要草稿", "已知字数和结构要求"]

steps: ["提取目的与贡献", "保留必要方法", "选择关键结果及原有数值", "删除非核心背景", "核对正文与摘要一致", "按实际期刊要求控制长度"]

outputs: ["独立可理解的摘要", "核心信息覆盖检查"]

missing_conditions: 无正文时不能验证全文一致性；不强制摘要含局限、展望、全部方法或固定句数。

## f10 — 围绕研究对象选择标题信息

任务：T07。来源：C 第7章 L6645–6665

summary: 先辨认标题中的研究对象，再决定是否需加入所做分析、目标或方法。 书中的X-of-Y-by-Z是常见结构的分析，不是唯一合法标题格式。 修改时使对象、贡献或方法关系明确，优先信息准确而非堆叠赞誉。

inputs: ["现有标题", "实际研究内容", "可得的期刊标题要求"]

steps: ["确定研究对象", "选择最有区分度且有证据的信息", "检查修饰范围", "删除空泛开头和重复", "与正文贡献对照"]

outputs: ["准确简洁的标题候选", "简短选择理由"]

missing_conditions: 不为套名词结构改变含义，不强制使用Investigation of等开头。

## f11 — 按真实关系选择句间衔接方式

任务：T08, T09。来源：G Unit1 §1.2.2 L298–368；C 附录A L15142

summary: 先判断两句是重复衔接、指代、因果、对比或让步，再选择最清楚的连接方式。 可用关键词承接、明确指代、关系从句或连接词，不必每句加过渡副词。 熟悉或较短的信息可作为进入新信息的起点。

inputs: ["相邻句子或一个段落", "作者原有逻辑关系"]

steps: ["写出前后句的实际关系", "检查术语承接与指代", "选择必要连接手段", "删除错误或重复过渡", "回读确认主语与关系未变"]

outputs: ["连贯句群", "必要的歧义说明"]

missing_conditions: 关系不明确时不擅自添加therefore等因果词；术语重复可以承担衔接功能。

## f12 — 用标题和关键首句建立反向提纲

任务：T01, T02, T05, T09, T14。来源：C 第18章 L14772–14828

missing_conditions: 提纲通顺不是全文逻辑成立的充分条件，仍须回读正文；不据固定模板重建已有有效结构。

## f13 — 核对引言承诺与研究实际完成内容

## f14 — 分层终审组织、语言与科学内容

## f15 — 使结论承担总结意义而非重复摘要

任务：T05, T07, T14。来源：W §10.10–10.12 L3986–4014；C 第5章 L4500–4506

summary: 摘要帮助读者快速获知工作整体；结论强调关键发现如何推进该领域及其含义。 对照两处删去机械复制，同时保留它们必须共享的核心事实。 局限、改进和后续工作只在有内容且位置合适时写入。

inputs: ["摘要", "结论", "主要发现及其依据"]

steps: ["列出共享事实", "保留结论需要的关键发现", "删去无功能的过程重述", "说明支持范围内的意义", "核对摘要结论没有新数据或力度漂移"]

outputs: ["功能明确的结论", "与摘要一致的核心主张"]

missing_conditions: W的演练内容是虚构材料；迁移组织方法，不迁移科学事实或它给出的应用断言。

## f16 — 从实质局限导出可执行的后续工作

任务：T05, T12。来源：G Unit4 L3473–3485、L3658–3664；C 第5章 L4556附近

summary: 讨论中选取影响当前解释且后续研究能处理的局限，连接具体研究方向。 不把领域固有困难或泛泛的需要更多研究写成每篇论文的固定结尾。 没有明确应用时不需要制造应用，局限的篇幅和位置还要适应文章约定。

inputs: ["实际研究局限", "可支持的后续问题", "讨论或结论草稿"]

missing_conditions: 原文未说明局限时不凭模板编造；本框架不要求给所有肯定句加保留语。
